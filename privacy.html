개인정보처리방침

Upload Console · 시행일 2026-10-16

1. 개요

Upload Console(이하 "이 앱")은 운영자 본인의 콘텐츠를 운영자 본인의 YouTube 채널, Instagram 계정, TikTok 계정에 업로드하기 위한 개인용 도구입니다. 운영자 외의 사용자는 이 앱을 사용하지 않습니다.

2. 접근하는 정보

  • YouTube(Google 계정): 영상 업로드 권한(youtube.upload)과, 연결된 채널 이름을 표시하기 위한 읽기 권한(youtube.readonly)을 사용합니다. 이를 위해 Google이 발급한 OAuth 토큰을 저장합니다.
  • Instagram: 게시물 발행을 위한 액세스 토큰과 계정 사용자 이름을 저장합니다.
  • TikTok: 연결된 계정 이름을 표시하기 위한 기본 정보 권한(user.info.basic)과, 영상을 TikTok 앱의 초안으로 보내는 권한(video.upload)을 사용합니다. 이를 위해 TikTok이 발급한 OAuth 토큰을 저장합니다. 게시 여부와 공개 범위는 운영자가 TikTok 앱에서 직접 정합니다.

3. 이용 목적

위 정보는 운영자가 직접 요청한 업로드를 수행하고, 연결 상태를 관리 화면에 표시하는 용도로만 사용합니다. 광고, 분석, 프로파일링 등 다른 목적으로 사용하지 않습니다.

4. 저장과 보호

토큰과 업로드 기록은 운영자의 개인 서버 데이터베이스에만 저장되며, 로그인한 운영자만 접근할 수 있습니다.

5. 제3자 제공

어떠한 정보도 제3자에게 판매하거나 제공하지 않습니다. 업로드 요청에 필요한 범위에서 YouTube(Google), Instagram(Meta), TikTok의 공식 API에만 전송됩니다.

6. 삭제

관리 화면에서 [연결 해제]를 누르면 저장된 토큰이 즉시 삭제됩니다. Google 계정의 접근 권한은 Google 계정 권한 설정에서, TikTok의 접근 권한은 TikTok 앱의 설정 → 보안 → 앱 및 서비스 관리에서 언제든지 철회할 수 있습니다.

7. Google API 서비스 사용자 데이터 정책

이 앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

Privacy Policy

Upload Console · Effective October 16, 2026

1. Overview

Upload Console ("the app") is a personal tool that uploads the operator's own content to the operator's own YouTube channel, Instagram account, and TikTok account. No one other than the operator uses this app.

2. Information accessed

  • YouTube (Google account): the app uses the video upload scope (youtube.upload) and a read-only scope (youtube.readonly) to display the connected channel name. It stores the OAuth tokens issued by Google for this purpose.
  • Instagram: the app stores an access token and the account username to publish posts.
  • TikTok: the app uses the basic profile scope (user.info.basic) to display the connected account name and the upload scope (video.upload) to send videos to the TikTok app as drafts. It stores the OAuth tokens issued by TikTok for this purpose. Whether and how a draft is posted is decided by the operator in the TikTok app.

3. How information is used

This information is used only to perform uploads the operator requests and to show connection status in the admin screen. It is not used for advertising, analytics, or profiling.

4. Storage and security

Tokens and upload records are stored only in the database on the operator's private server and are accessible only to the logged-in operator.

5. Sharing

No information is sold or shared with third parties. Data is sent only to the official YouTube (Google), Instagram (Meta), and TikTok APIs as needed to perform uploads.

6. Deletion

Selecting "Disconnect" in the admin screen deletes the stored tokens immediately. Google account access can be revoked at any time in Google Account permissions, and TikTok access in the TikTok app under Settings → Security → Manage app permissions.

7. Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
